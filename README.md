# MYPAGE · 王释贤的个人主页

一个纯静态的个人主页。无框架、无构建工具、无依赖——**双击 `index.html` 就能打开**。

> 目前处于 V2 阶段（视觉打磨 + 内容升级）。V3 计划：反馈表单 + 后台数据库 + 部署上线。

---

## 这是什么

先给同学朋友看，将来给 HR / 面试官看。所以它不只是「一页介绍」，而是尽量让**每条声明后面都跟着证据**：

- 说「在做项目」→ 就给出项目条目、版本线、提交历史
- 说「关注脑机接口 × AI」→ 就给出方向卡片
- 说「会写前端」→ 这个页面本身就是证据（自己写的设计系统，见 `DESIGN-SYSTEM.md`）

## 技术栈

| | |
|---|---|
| 形态 | 纯静态三文件：`index.html` + `style.css` + `script.js` |
| 框架 | 无。不用 React / Vue / Tailwind，不用 npm 与打包器 |
| 字体 | 系统字体（PingFang SC / 微软雅黑），不加载外部字体 |
| 第三方 | 无 CDN、无追踪脚本。页面数据不联网上传 |
| 浏览器要求 | 现代浏览器；关闭 JS 或开启「减少动效」时内容仍可正常阅读 |

## 数字分身：两个大脑

聊天区那一块有两个大脑，**掉线自动降级**：

| | 是什么 | 什么时候用 |
| --- | --- | --- |
| ① **本地知识库**（`script.js` 的 `KNOWLEDGE`） | 几条关键词匹配的固定回答，跑在浏览器里 | **地板**。0 依赖、0 延迟、**永远可用** —— 页面打开就答得上话 |
| ② **WeClone 微调分身** | 用聊天记录微调出来的模型，走 OpenAI 兼容 API | **天花板**。`CHAT_BACKEND.url` 填上地址即启用 |

②出任何问题（超时 / 非 200 / 坏 JSON / 空回复 / 被跨域拦）⇒ **自动落回 ①**，
并在气泡下加一个「离线版回答」的小标记（如实说明这句不是分身本体答的）。
连续失败 2 次还会**跳闸 2 分钟** —— 否则后端一挂，访客每问一句都要干等 8 秒。

> 这套「地板 + 天花板」是为了守住站点的一条底线：**纯静态、打开就能用**。
> 给 HR / 面试官看的页面，点开必须答得上话。完整链路（装环境 → 导记录 → 清洗 → 微调 →
> 起服务 → 填地址）与三个必踩的坑见 **[`WECLONE.md`](WECLONE.md)**。

## 设计上几个刻意的决定

- **全站只有 6 个颜色**（`--c-ink / --c-muted / --c-brand / --c-mint / --c-bg / --c-surface`）。
  层次靠一条透明度派生通道 `--c-brand-rgb` 做，不新建色阶。想加颜色前先问「能不能用透明度派生」
- **渐变只往暗里走**。往亮走会让白字对比度掉到 2.5:1（低于 WCAG AA 的 4.5:1）
- **文字用逐行入场，容器用整块淡入**。逐行是 JS 按渲染后的实际换行拆的，不是硬编码
- **尊重 `prefers-reduced-motion`**。用 `animation-duration: .01ms` 而不是 `animation: none`
  —— 后者会让 `fill-mode: both` 的动画卡在 `opacity: 0`，内容直接消失
- **易过时的数字交给脚本，不靠人记**。页面上那句「共 N 次提交」今天手工改过 4 次——
  每提交一次它就过时一次。现在由 `tools/sync-version.py` 从 `git rev-list --count` 读出来写回，
  提交前跑一次即可。它会把**正在准备的这一次**也算上：数字描述的是「提交之后」的状态，
  不加一的话提交完立刻就差 1
- **首屏那个玻璃泡泡是「按机制重做」，不是抄来的**。灵感来自 CodePen 上的一个 pen，
  但它的源码抓不到，所以这里是从机制自己搭的：环形文字用 SVG `textPath` 挂在整圆上匀速转；
  玻璃用「圆形裁切 + 高光边 + SVG 位移滤镜做**边缘**折射」。
  **滤镜只加在静态图片层、不加在旋转文字上**——挂在旋转元素上会变成每帧逐像素重算。
  泡泡里的照片是本人拍的 `3.jpg`；它偏暖橙，而本站是冷青，所以叠了一层青色玻璃染色统一色调
  （**原图没改**，想还原暖色删一行就行）。整个泡泡标记为 `aria-hidden`，因为它是视觉装置，
  照片在「摄影集」区块已有完整 alt

- **整页尺寸只有一个旋钮**。字号 / 间距 / 圆角 / 页宽 / 元件尺寸全都从 `--scale` 派生，
  改这一处全站一起动（见 `DESIGN-SYSTEM.md` §5.1）。
  ⚠️ 区块间距与窄屏那几条硬编码**刻意不乘它**，理由写在那一节里
- **文档会腐烂，所以有脚本盯着**：`tools/check-doc-vs-css.py` 核对设计文档里写的数值
  与样式表实际值是否一致（含「每个被提到的 token 都真的存在」）。改完样式顺手跑一次

更完整的规范（含对比度校验表）见 `DESIGN-SYSTEM.md`。

## 无障碍

- 小字号（≤12px）用 `--color-muted` 或 `--color-brand`，两种主题下都过 WCAG AA
  （实测：次要灰 **浅色 7.27:1 / 深色 9.45:1**；强调青 **浅色 5.47:1 / 深色 12.80:1**）
- 装饰性元素（Marquee 横幅、背景网格）加 `aria-hidden`，不被读屏朗读
- 键盘焦点有 `:focus-visible` 描边
- 不隐藏系统光标（这条是刻意的：隐藏后点不准、看不清输入位置）
- 关闭 JS 时用 `<noscript>` 兜底，内容照常显示

## 关于 AI 协作

这个页面是在 AI 辅助下完成的，过程如实记录在 `过程证据/AI使用日志.md`（位于本仓库之外）。
分工是：**AI 写代码，我做判断**——需求、审美取舍、范围控制、验收都归我。
AI 生成的代码我会逐段复核，发现过真实缺陷并修掉（渐变方向导致的对比度不达标、
`animation: none` 导致内容消失、并行编辑同一文件互相覆盖）。

设计上的借鉴只停留在「思路」层面：参考了 serious.business 的配色克制与逐行入场、
betteroff.studio 的 Marquee 元素，**不复制任何文字、图片、品牌与源码**。
