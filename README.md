# MYPAGE · 王释贤的个人主页

一个纯静态的个人主页。无框架、无构建工具、无依赖——**双击 `index.html` 就能打开**。

> 目前处于 V2 阶段（视觉打磨 + 内容升级）。V3 计划：反馈表单 + 后台数据库 + 部署上线。

---

## 这是什么

先给同学朋友看，将来给 HR / 面试官看。所以它不只是「一页介绍」，而是尽量让**每条声明后面都跟着证据**：

- 说「在做项目」→ 就给出项目条目、版本线、提交历史
- 说「关注脑机接口 × AI」→ 就给出方向卡片
- 说「会写前端」→ 这个页面本身就是证据（自己写的设计系统，见 `DESIGN-SYSTEM.md`）

## 技术栈

| | |
|---|---|
| 形态 | 纯静态三文件：`index.html` + `style.css` + `script.js` |
| 框架 | 无。不用 React / Vue / Tailwind，不用 npm 与打包器 |
| 字体 | 系统字体（PingFang SC / 微软雅黑），不加载外部字体 |
| 第三方 | 无 CDN、无追踪脚本。页面数据不联网上传 |
| 浏览器要求 | 现代浏览器；关闭 JS 或开启「减少动效」时内容仍可正常阅读 |

## 设计上几个刻意的决定

- **全站只有 6 个颜色**（`--c-ink / --c-muted / --c-brand / --c-mint / --c-bg / --c-surface`）。
  层次靠一条透明度派生通道 `--c-brand-rgb` 做，不新建色阶。想加颜色前先问「能不能用透明度派生」
- **渐变只往暗里走**。往亮走会让白字对比度掉到 2.5:1（低于 WCAG AA 的 4.5:1）
- **文字用逐行入场，容器用整块淡入**。逐行是 JS 按渲染后的实际换行拆的，不是硬编码
- **尊重 `prefers-reduced-motion`**。用 `animation-duration: .01ms` 而不是 `animation: none`
  —— 后者会让 `fill-mode: both` 的动画卡在 `opacity: 0`，内容直接消失

更完整的规范（含对比度校验表）见 `DESIGN-SYSTEM.md`。

## 无障碍

- 小字号（≤12px）一律使用 `--color-brand`，对比度 4.9:1，过 WCAG AA
- 装饰性元素（Marquee 横幅、背景网格）加 `aria-hidden`，不被读屏朗读
- 键盘焦点有 `:focus-visible` 描边
- 不隐藏系统光标（这条是刻意的：隐藏后点不准、看不清输入位置）
- 关闭 JS 时用 `<noscript>` 兜底，内容照常显示

## 关于 AI 协作

这个页面是在 AI 辅助下完成的，过程如实记录在 `过程证据/AI使用日志.md`（位于本仓库之外）。
分工是：**AI 写代码，我做判断**——需求、审美取舍、范围控制、验收都归我。
AI 生成的代码我会逐段复核，发现过真实缺陷并修掉（渐变方向导致的对比度不达标、
`animation: none` 导致内容消失、并行编辑同一文件互相覆盖）。

设计上的借鉴只停留在「思路」层面：参考了 serious.business 的配色克制与逐行入场、
betteroff.studio 的 Marquee 元素，**不复制任何文字、图片、品牌与源码**。
